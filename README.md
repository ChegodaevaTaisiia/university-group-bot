# Бот студенческой группы

Телеграм-бот для старосты: расписание, домашка, личные напоминания, ИИ-ассистент
по вопросам об учёбе, рассылки в супергруппу.

## Что уже умеет

| Раздел | Кто | Описание |
|---|---|---|
| 📅 Расписание | все | сегодня / завтра / неделя, с учётом числителя-знаменателя |
| | староста | импорт расписания текстом (`/schedule_import`), публикация в чат (`/schedule_post`) |
| ⏰ Напоминания | все | личные: текст → когда («15 сентября 10:00», «через 2 часа», «в понедельник 8:00») → за сколько предупредить → повтор |
| 📚 Домашка | все | добавить задание (текст или фото доски); если то же самое прислал ещё кто-то — бот подтверждает и публикует в тему предмета |
| | староста | `/answer`, подтвердить вручную (кнопка в «Управление») |
| 🤖 Спросить бота | все | свободный вопрос → ответ по базе знаний (преподаватели, деканат); если не знает — пересылает старосте |
| ❓ ЧаВо | все | список частых вопросов |
| ⚙️ Управление | староста | рассылка всем, привязка тем к предметам, список группы, база знаний, тест ИИ |

Разделы **Посещаемость**, **Документы**, **Защиты** — в планах (следующий этап).

## Требования

- Python 3.11+ (или Docker)
- Бот в @BotFather
- Супергруппа с темами (topics), бот добавлен туда администратором
- (опционально) ключ Anthropic API для ИИ-функций

## Быстрый старт локально

```bash
python -m venv .venv
.venv\Scripts\pip install -e ".[dev]"     # Windows
# source .venv/bin/activate && pip install -e ".[dev]"   # Linux/Mac
cp .env.example .env                       # заполнить BOT_TOKEN, ADMIN_IDS, SUPERGROUP_ID
python -m bot.main
```

Миграции БД применяются автоматически при старте.

## Деплой на VPS через Docker (рекомендуется)

```bash
# на сервере:
git clone <репозиторий> group-bot && cd group-bot
cp .env.example .env && nano .env          # заполнить значения
docker compose up -d --build
docker compose logs -f bot                 # проверить, что запустился
```

Данные (БД, файлы) лежат в volume `bot_data` и переживают перезапуск/пересборку.

Обновление после изменений в коде:

```bash
git pull && docker compose up -d --build
```

## Настройка `.env`

| Переменная | Обязательна | Что это |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather |
| `ADMIN_IDS` | да | твой Telegram id (узнать: @userinfobot); можно несколько через запятую |
| `SUPERGROUP_ID` | желательно | id супергруппы; узнать: добавь бота в группу и напиши там `/chatid` |
| `TIMEZONE` | нет | по умолчанию `Europe/Moscow` |
| `SEMESTER_START` | нет | понедельник 1-й (нечётной) недели семестра — от него считается числитель/знаменатель |
| `ANTHROPIC_API_KEY` | нет | без него бот работает, но без ИИ-ответов |
| `AI_MODEL` | нет | по умолчанию `claude-haiku-4-5` (самая дешёвая) |
| `AI_MONTHLY_BUDGET_USD` | нет | потолок расходов на ИИ в месяц; при превышении ИИ-ответы выключаются |
| `AI_USER_HOURLY_LIMIT` | нет | сколько ИИ-вопросов в час на одного студента |

### Как привязать темы супергруппы к предметам

Зайди в нужную тему супергруппы и напиши:

```
/bind_subject Матанализ
```

Теперь подтверждённые задания по матанализу бот будет публиковать в эту тему.

## Как получить ключ Anthropic API (для ИИ)

1. Зарегистрируйся на **console.anthropic.com**.
2. **Billing** → пополни баланс (хватит минимального; расход при группе ~30 человек —
   несколько центов в месяц на модели Haiku).
3. **API Keys** → *Create Key* → скопируй (`sk-ant-...`).
4. Вставь в `.env`: `ANTHROPIC_API_KEY=sk-ant-...`, при желании поставь
   `AI_MONTHLY_BUDGET_USD=5`.
5. Перезапусти бота, в меню «Управление» → «Проверить ИИ» (или `/ai_selftest`).

### База знаний

- `/kb_refresh` — тянет с сайта РЭУ всех преподавателей твоей высшей школы
  (ФИО, должность, кафедра) + контакты дирекции. Раз в неделю обновляется само.
  Страница школы задаётся в `.env` → `KB_SCHOOL_URL`.
- `/kb_enrich <фамилия>` — подтягивает со страницы преподавателя почту, кабинет,
  часы приёма и список предметов (через ИИ). Делай для тех, кто ведёт у вас.
- `/kb_add`, `/kb_del <id>` — записи вручную (деканат, свои заметки и т.п.).
